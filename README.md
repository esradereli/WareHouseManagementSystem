# Warehouse Management System (C++)

This project is a simple Warehouse Management System developed in C++ to improve object-oriented programming skills and warehouse logic management.

The system allows users to manage different types of products, control stock operations, and generate warehouse reports through a console-based interface.

## Features

- Add and delete products
- Increase or decrease stock quantity
- Display all stored products
- Generate warehouse reports
- Product type categorization
- Storage cost calculations
- Volume tracking system

## Product Types

The project includes multiple product categories:

- General Products
- Heavy Products
- Fragile Products
- Nuclear Products

Each product type has its own storage cost calculation and special properties.

## Concepts Used

This project was developed using object-oriented programming concepts such as:

- Classes and Objects
- Inheritance
- Polymorphism
- Abstract Classes
- Virtual Functions
- Function Overloading
- Friend Functions
- Constructors & Destructors
- Struct Usage
- Dynamic Memory Management

## Technologies

- C++
- Dev-C++
- Console Application

## How to Run

1. Open the project in Dev-C++ or any C++ IDE
2. Compile the source files
3. Run the executable file

## Purpose of the Project

The main purpose of this project is to practice object-oriented programming principles while building a functional warehouse management simulation.
